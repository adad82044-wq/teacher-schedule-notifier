# 🌸 ระบบแจ้งเตือนตารางสอน (คาบละ 40 นาที) - โรงเรียนสารวิทยา
**สำหรับ: ครูทวีวัฒน์ คีรีสูงเนิน (ครูเม่น) และคุณครูโรงเรียนสารวิทยา**  
*ภาคเรียนที่ 2 ปีการศึกษา 2569*

โปรแกรมแจ้งเตือนเวลาเข้าสอนบนหน้าจอคอมพิวเตอร์ (Windows Desktop Notification) ออกแบบมาเป็นพิเศษสำหรับโรงเรียนที่มีการร่นเวลาคาบสอนลงคาบละ 10 นาที (เหลือคาบละ 40 นาที) ช่วยแก้ปัญหาจำเวลาเริ่มคาบไม่ได้ พร้อมระบบ AI สแกนตารางสอนจากรูปภาพอัตโนมัติ

---

## ✨ คุณสมบัติเด่น (Features)

1. **🔔 แจ้งเตือนล่วงหน้า 1 คาบ (Advance Warning):**
   * เตือนตั้งแต่ต้นคาบก่อนหน้า เช่น ณ เวลา **08:20 น.** (ต้นคาบ 1) ระบบจะเด้งเตือน **คาบที่ 2 (09:00 น.)** ทันที เพื่อให้คุณครูมีเวลาเตรียมตัวล่วงหน้าตลอดคาบ
2. **📌 การ์ดแจ้งเตือน Always-on-top + ปุ่ม [ รับทราบ ]:**
   * การ์ดจะลอยอยู่มุมล่างขวาของหน้าจอ และ **ไม่หายไปเอง** จนกว่าจะกดปุ่ม **`[ รับทราบ ]`**
   * ลากย้ายตำแหน่งบนหน้าจอได้อิสระ
3. **🔄 ระบบ Auto-Rollover (แทนที่อัตโนมัติเมื่อเข้าคาบใหม่):**
   * หากคุณครูติดสอนหรือไม่ได้กดรับทราบ เมื่อถึงเวลาแจ้งเตือนคาบถัดไป ระบบจะปิดการ์ดเดิมให้อัตโนมัติ แล้วเปิดการ์ดของคาบถัดไปขึ้นมาแทนทันที
4. **☕ ระบบแจ้งเตือนคาบว่างอัจฉริยะ:**
   * หากคาบถัดไปไม่มีสอน จะแจ้งว่า *"คุณครูว่าง ไม่มีสอนค่ะ"* พร้อมบอกเวลาและวิชาที่จะมีสอนในคาบถัดไปของวันทันที
5. **🌅 ระบบสรุปสถานะย้อนหลัง (Startup Catch-up):**
   * หากเปิดคอมพิวเตอร์ช้ากว่าปกติในเวลาเรียน ระบบจะสรุปสถานะทันทีว่า *ขณะนี้อยู่คาบใด และคาบถัดไปมีสอนหรือไม่*
6. **📷 อัปเดตตารางสอนด้วย AI (Gemini Vision):**
   * สแกนตารางสอนได้จากไฟล์รูปภาพ หรือกดปุ่ม `Windows + Shift + S` แล้วกด **`Ctrl + V`** วางรูปที่แคปหน้าจอได้ทันที AI จะกรอกวิชา ห้องเรียน และสถานที่ลงตาราง 40 นาทีให้อัตโนมัติใน 5 วินาที
7. **🔇 เงียบ ไม่มีเสียงรบกวน (Silent):**
   * ไม่ส่งเสียงแจ้งเตือนรบกวนบรรยากาศการสอนในห้องเรียน
8. **⚙️ เปิดทำงานอัตโนมัติพร้อม Windows:**
   * กดปุ่มตั้งเปิดพร้อม Windows เพียงครั้งเดียว ระบบจะทำงานเงียบๆ ในพื้นหลังทุกครั้งที่เปิดเครื่อง

## 📥 วิธีดาวน์โหลดและใช้งาน (สำหรับคุณครูทั่วไป)

1. ดาวน์โหลดไฟล์ **`ระบบแจ้งเตือนตารางสอน_สารวิทยา.zip`** จากหน้า [Releases](../../releases)
2. แตกไฟล์ ZIP ไว้ที่หน้าจอ Desktop หรือโฟลเดอร์ที่สะดวก
3. ดับเบิ้ลคลิกเปิดโปรแกรม **`ระบบแจ้งเตือนตารางสอน.exe`**
4. กดปุ่ม **`📷 เลือกรูปตารางสอน`** หรือกด `Windows + Shift + S` แคปรูปตารางสอนแล้วมากด **`📋 วางรูปที่แคปหน้าจอ (Ctrl+V)`** เพื่อให้ AI อ่านตารางสอน
5. กดปุ่ม **`⚙ ตั้งเปิดพร้อม Windows`** แล้วเริ่มใช้งานได้ทันทีครับ!

## 💻 สำหรับนักพัฒนา (Developer Guide)

### โครงสร้างไฟล์
* `teacher_notifier.pyw` : เซอร์วิสเบื้องหลังตรวจเวลาและแสดงการ์ด Always-on-Top
* `control_panel.pyw` : หน้าต่างควบคุม ดูตารางสอนรายวัน แก้ไขรายคาบ สแกนรูป AI และตั้งค่าระบบ
* `image_scanner.py` : โมดูลเชื่อมต่อ Google Gemini Multimodal Vision API สำหรับอ่านตารางสอนภาษาไทย
* `schedule_data.json` : ฐานข้อมูลตารางสอนและเวลาคาบ

### การรันจาก Source Code
```bash
# ติดตั้ง Library ที่จำเป็น
pip install pillow requests

# รันหน้าต่างควบคุม
pythonw control_panel.pyw

# รันเซอร์วิสแจ้งเตือนเบื้องหลัง
pythonw teacher_notifier.pyw
```
